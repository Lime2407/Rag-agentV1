# 📚 RAG Agent — чат с твоими документами (Ollama + ChromaDB)

Локальный AI-агент, который отвечает на вопросы по твоим собственным документам
(RAG — Retrieval-Augmented Generation). Полностью работает на своём компьютере,
без API-ключей и без отправки данных в облако.

## Как это работает

1. **Чанкинг** — документы из папки `documents/` режутся на небольшие
   пересекающиеся фрагменты текста
2. **Эмбеддинги** — каждый фрагмент превращается в вектор через модель
   `nomic-embed-text` (через Ollama)
3. **Векторная база** — эмбеддинги сохраняются в локальной базе ChromaDB
4. **Поиск** — при вопросе пользователя система ищет самые похожие по смыслу
   фрагменты текста
5. **Генерация** — найденный контекст подставляется в промпт LLM, которая
   формирует ответ, опираясь только на реальные документы

## Установка

1. Установите Ollama: https://ollama.com

2. Скачайте нужные модели:
   ```bash
   ollama pull llama3.1
   ollama pull nomic-embed-text
   ```

3. Установите Python-зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Запуск

Положите свои `.txt` файлы в папку `documents/` (там уже лежит пример `sample.txt`
про Ollama и RAG — можно протестировать прямо сейчас).

```bash
python rag_agent.py
```

При первом запуске агент автоматически проиндексирует документы. Дальше можно
просто задавать вопросы:

```
Вы: Что такое RAG?
Агент: RAG (Retrieval-Augmented Generation) — это техника, которая объединяет
поиск информации с генерацией текста...

Вы: Какие модели поддерживает Ollama?
Агент: Ollama поддерживает Llama, Mistral, Qwen, Gemma и другие open-source модели...
```

Команды в чате:
- `reindex` — пересобрать базу, если добавил новые документы
- `exit` — выход


## Как расширить проект

- Добавьте поддержку PDF/DOCX (через `pypdf`, `python-docx`) вместо только `.txt`
- Покажите в ответе, из какого именно документа взята информация (источники уже
  сохраняются в метаданных ChromaDB)
- Замените линейный чанкинг на разбиение по предложениям/абзацам для лучшего качества
- Добавьте веб-интерфейс через Streamlit — хороший штрих для портфолио
- Объедините с tool-calling агентом из предыдущего проекта: RAG как один из инструментов

## Технологии

- Python 3.10+
- [Ollama](https://ollama.com) — локальный запуск LLM и эмбеддингов
- [ChromaDB](https://www.trychroma.com) — локальная векторная база данных
- Модели: Llama 3.1 (генерация) + nomic-embed-text (эмбеддинги)
