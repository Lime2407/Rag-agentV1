Ollama — это инструмент с открытым исходным кодом для локального запуска больших языковых моделей (LLM) на своём компьютере, без необходимости отправлять данные в облако.

Главные возможности Ollama:
- Запуск популярных open-source моделей: Llama, Mistral, Qwen, Gemma и других
- Полностью бесплатное использование без ограничений по токенам
- Поддержка tool calling (вызова функций) начиная с ряда моделей, включая Llama 3.1 и новее
- Простой API, похожий на REST, доступный на localhost:11434
- Официальные библиотеки для Python и JavaScript

Ollama особенно полезна для обучения и разработки AI-агентов, потому что не требует API-ключей и позволяет экспериментировать без ограничений по стоимости.

RAG (Retrieval-Augmented Generation) — это техника, которая объединяет поиск информации с генерацией текста. Вместо того чтобы полагаться только на знания, заложенные при обучении модели, RAG-система находит релевantные фрагменты из внешней базы документов и добавляет их в промпт модели в качестве контекста.

Основные компоненты RAG-системы:
1. Чанкинг (chunking) — разбиение документов на небольшие фрагменты
2. Эмбеддинги (embeddings) — превращение текста в числовые векторы, отражающие смысл
3. Векторная база данных — хранилище для быстрого поиска похожих по смыслу фрагментов (ChromaDB, FAISS, Pinecone)
4. Генерация ответа — модель формирует ответ на основе найденного контекста

RAG особенно полезен для работы с приватными или часто обновляемыми данными, такими как внутренняя документация компании, личные заметки или свежие новости.
